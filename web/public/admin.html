Data & Model Evaluation

Individual A/B preference rounds, goal progress, model head-to-head comparisons, per-prompt breakdown, and dataset exports.

A/B rounds per labeller (individual rounds)

Counted from individual A/B pair answers in D.ab (never batches). Decisive model picks count A or B choices on head-to-head model pairs (excluding same-model hidden calibration checks). Click any labeller to inspect their picks.

A/B preference head-to-head

One row per labeller group; status overrides apply the same way (excluded labellers only appear in "Everyone"). Hidden calibration pairs (the owner's decisive local A/B picks, both sides the same model) are left out here and only feed the A/B agreement score.

Archived data (before the v3 switch, 12 Nov 2026)

Old A/B votes, chat votes and pool files were copied, not deleted. They do not count toward the new v3 pool. Export leaves the originals in place.

Export archived: A/B jsonl · A/B csv · chat jsonl · chat csv · grid jsonl

Grid head-to-head (works-rate per model)

Calibration rounds are left out of web labellers' head-to-head (they are the owner's old rounds). "Owner" = the owner's import + IDs set to owner. "Trusted" = owners + IDs set to trusted + auto-trusted (status auto and either ≥3 grid reference rounds with agreement κ ≥ threshold, or ≥4 A/B calibration pairs with ≥60% agreement; and no quality flags). Excluded IDs are never trusted.

Export dataset

Per-labeller JSONL and CSV exports are also available inside each labeller's review drawer. Flywheel v2 exports deduplicated, holdout-safe DPO/reward tuples with candidate arrays, explicit/implicit weights, and user 16×16 edit diffs.
